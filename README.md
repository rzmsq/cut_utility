# Утилита Cut на Go

Простая реализация утилиты `cut` на языке Go. Утилита предназначена для извлечения полей (колонок) из строк текста.

## Возможности

-   Выбор колонок для извлечения.
-   Поддержка кастомного разделителя.
-   Возможность обрабатывать только строки, содержащие разделитель.

## Использование

### Сборка

Для сборки проекта выполните:

```bash
go build -o cut_utility ./cmd/main.go
```

### Флаги

-   `-f`: Номера колонок для извлечения. Можно указывать через запятую (например, `1,3`) или в виде диапазона (например, `1-3`). Нумерация начинается с 1.
-   `-d`: Разделитель колонок. По умолчанию используется символ табуляции (`\t`).
-   `-s`: Обрабатывать только те строки, которые содержат разделитель.

### Примеры

Предположим, у нас есть файл `data.txt` со следующим содержимым:

```
field1,field2,field3
a,b,c
x,y,z
```

1.  **Извлечь первую и третью колонку с разделителем ",":**

    ```bash
    cat data.txt | go run ./cmd/main.go -f 1,3 -d ","
    ```

    Вывод:

    ```
    field1,field3
    a,c
    x,z
    ```

2.  **Извлечь вторую колонку:**

    ```bash
    cat data.txt | go run ./cmd/main.go -f 2 -d ","
    ```

    Вывод:

    ```
    field2
    b
    y
    ```

3.  **Использовать флаг `-s`:**

    `data_mixed.txt`:
    ```
    field1,field2,field3
    no_delimiter_here
    a,b,c
    ```

    ```bash
    cat data_mixed.txt | go run ./cmd/main.go -f 1 -d "," -s
    ```

    Вывод (строка "no_delimiter_here" будет проигнорирована):

    ```
    field1
    a
    ```

## Разработка

В проекте используется `Makefile` 

-   `make fmt`: Проверка форматирования кода с помощью `gofmt`.
-   `make lint`: Запуск статического анализатора `golangci-lint`. При необходимости `golangci-lint` будет установлен автоматически.
-   `make test`: Запуск всех тестов.
-   `make coverage`: Запуск тестов с анализом покрытия кода.
-   `make all`: Выполнение всех проверок (`fmt`, `lint`, `test`).
-   `make clean`: Удаление временных файлов, созданных при анализе покрытия.
